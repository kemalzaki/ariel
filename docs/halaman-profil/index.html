Design Brief: Halaman Profil Diri

Fitur: satu halaman profil diri HTML5 untuk tugas kuliah (Pemrograman Web). Tujuan bisnis: memenuhi seluruh kriteria penilaian (struktur 25%, aksesibilitas 25%, metadata 25%, kerapihan 25%) dan lulus pemeriksaan dosen saat URL dibuka di hosting.

1. Ringkasan

Ariel diminta membuat halaman profil diri berisi foto, biodata, tabel mata kuliah semester ini, minimal satu tautan, dan metadata (title, description, og:title, og:description, og:image). Yang dikumpulkan hanya URL, jadi halaman harus tampil benar di hosting statis mana pun, tanpa proses build di sisi server. Repo ini adalah situs portofolio Astro milik Ariel; halaman tugas harus hidup berdampingan dengannya tanpa mengubah portofolio.

2. Keputusan build

KeputusanPilihanAlasan
Cara memenuhi "buat file index.html" HTML murni tulis tangan di public/profil/index.html Tugas menuntut file index.html yang strukturnya dinilai dari kode sumbernya. Folder public/ Astro disalin apa adanya saat build, jadi halaman otomatis tersedia di path /profil/ kalau repo ini di-deploy, dan foldernya juga bisa di-upload sendiri ke hosting mana pun. Portofolio di root tidak tersentuh.
Penyajian halaman Satu file mandiri: HTML + CSS inline, nol JavaScript Nol JS berarti nol titik gagal di browser dosen; CSS inline menjaga satu file tetap rapi dibaca. Tidak ada dependensi build.
Tipografi IBM Plex Mono dari Google Fonts dengan fallback monospace sistem Sama dengan portofolio agar dua situs terasa satu identitas. Kalau font gagal dimuat, halaman tetap terbaca dengan font monospace sistem.
Foto diri Placeholder PNG digenerate (siluet avatar) berukuran 1200x1200 Foto asli milik Ariel dan harus diganti sebelum dikumpulkan. Satu file dipakai untuk tampilan halaman sekaligus og:image. JPG/PNG dipilih karena crawler media sosial tidak mendukung SVG.
og:image Path relatif foto-profil.png + komentar TODO Domain hosting belum diketahui. Sebagian crawler butuh URL absolut, jadi nilai ini wajib diperbarui begitu domain final ada.
Data isi (NIM, angkatan, daftar mata kuliah) Diisi nilai wajar sebagai asumsi, ditandai TODO di kode dan laporan Nilai aslinya hanya diketahui Ariel. Struktur halaman tidak berubah saat data diganti, tinggal edit teks.

3. Alur utama

flowchart TD A[Dosen membuka URL profil] --> B[Browser memuat index.html] B --> C[Metadata terbaca: title, description, og] B --> D[Halaman dirender: header, nav, main, footer] D --> E{Dosen berpindah bagian} E -->|Klik nav| F[Lompat ke anchor section] E -->|Gulir| G[Baca biodata dan tabel mata kuliah] E -->|Klik tautan kontak| H[Email atau situs kampus terbuka] G --> I[Tabel digulir horizontal di layar sempit]

4. Peta sistem dan aktor

Aktor: dosen (menilai lewat URL), Ariel (mengganti foto dan data diri), crawler media sosial (membaca og:image saat tautan dibagikan).

Peta: browser dosen meminta /profil/index.html dari hosting statis. Sumbernya bisa repo Astro ini (build menyalin folder public/profil/ ke hasil build) atau hasil upload manual folder profil/. Tidak ada server aplikasi, tidak ada database, tidak ada panggilan API dari halaman. Satu-satunya permintaan eksternal adalah font Google Fonts.

6. Skenario negatif

KondisiPerilaku yang diharapkan
Layar 375pxTidak ada scroll horizontal halaman; tabel bisa digulir sendiri di wadahnya, foto pindah ke atas konten
Font Google gagal dimuatFallback font monospace sistem, tata letak tidak rusak
JavaScript dimatikanHalaman berfungsi penuh karena memang tidak memakai JavaScript
Foto belum diganti dari placeholderHalaman tetap rapi; alt tetap deskriptif; dicegah lupa lewat catatan TODO di kode dan laporan
og:image masih relatif saat URL dibagikanSebagian crawler mengabaikannya; sudah ditandai TODO menunggu domain final
Folder profil di-upload tanpa file fotoAlt text tampil sebagai pengganti, layout tidak kolaps

7. Titik verifikasi terbuka dan langkah berikutnya

  • Ariel mengganti foto-profil.png dengan foto asli (nama file tetap sama supaya og:image ikut benar)
  • Ariel melengkapi NIM, angkatan, dan mengoreksi daftar mata kuliah beserta SKS dan jadwalnya
  • Domain final: https://ariel-chi.vercel.app (deploy via Vercel); og:image sudah diganti ke URL absolut
  • Metode pengumpulan ditentukan: deploy repo Astro (path otomatis /profil/) atau upload folder profil/ ke hosting tugas
